# eDiye® Design Studio

A pixel-perfect, high-performance web experience built for **eDiye® Studio** — an elite branding, UI/UX design, and digital development studio.

## 🚀 Overview
- **Design Tokens**: Standardized design system based on Framer specifications (css/tokens.css, STYLE_GUIDE.md).
- **Typography**: Inter typography hierarchy with custom letter spacing and tight leading.
- **Icons**: Phosphor Duotone icon set (ph-duotone).
- **Animations**: Custom scroll-driven word reveals, smooth transitions with custom cubic bezier easing, and interactive pricing slider widgets.
- **Pages**:
  - index.html - Main Studio Landing Page (Hero, Statement, Benefits, Case Studies, Methodology, Services, Pricing, FAQ, Contact)
  - bout.html - Studio Philosophy, Mission, and Team
  - works.html - Portfolio / Selected Case Studies index
  - works/hectic.html, works/korten.html, works/everly.html, works/peni.html - In-depth Case Studies
  - shopify.html - Dedicated E-commerce & Shopify services
  - rticles.html - Journal & Design Insights
  - contact.html - Direct project inquiry & onboarding
  - privacy-policy.html & 	erms-of-service.html - Legal & Policies

## 🛠 Tech Stack
- **HTML5** (Semantic architecture)
- **CSS3** (CSS Custom Properties / Design Tokens, Flexbox, 3-Column CSS Grid)
- **Vanilla JavaScript (ES6+)** (Zero external runtime dependencies)
- **Phosphor Icons** (Duotone edition)
